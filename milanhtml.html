About this project

Maritime Port Container Management

PROJECT INFO

This student project demonstrates how a simplified port operations website can organize container records, vessel assignments, yard locations, availability and container movement history.

The eight screens are built using HTML and CSS. Click the menu on the left to switch between screens. All records and figures shown are sample data for demonstration only.

This version is a static front-end project. It does not store changes or connect to a live port system.

Project goals

  • Organize container information in a clear table.
  • Show vessel assignments and expected arrivals.
  • Display yard locations and recent container movements.
  • Present a simple operational summary.
